# Supermarket-Sales-Analysis

## Tools used: - Microsoft Excel

## Project Overview: - 
This project analyzes supermarket sales data to uncover key business insights using pivot tables and data visualization.

## Key Questions Answered: -
1. Which product line generates the most revenue?
2. Which city has the highest sales?
3. What time of the day drives the most sales?

## Key Insights: - 
- Food and Beverage products are the top revenue drivers, outperforming all the other categories.
- Naypyitaw leads in total sales which indicate a stronger market performance overall.
- Sales peak in the evening at around 7PM which suggests there's higher customer activity during this period.
